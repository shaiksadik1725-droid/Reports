## About This Portfolio

This repository is the index for selected academic and engineering projects by **Sadik Shaik**. The work spans applied AI, embedded systems, IoT, biomedical engineering, environmental monitoring, and digital communication.

The goal of the portfolio is to show complete engineering workflows: **problem definition → sensing/data → algorithm or model → implementation → interface → evaluation**.
